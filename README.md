# Godzilla: Save the Earth Model Viewer

A browser 3D viewer for the monsters of *Godzilla: Save the Earth* (PS2): meshes, textures, skeletons and animations.
A fan project by TwistZero, built the same way as the [War of the Monsters Model Museum](https://github.com/yanm1103/wotm-model-museum).

**Status: not built yet.** `INSTRUCTIONS.md` is the plan (written for Claude); `reference/` has the working Python that decodes the
game and the documentation of the file formats.

This repo never contains the game or its raw files.
